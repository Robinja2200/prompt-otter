# Prompt Otter Privacy Policy

Prompt Otter is a local browser extension for navigating prompts in ChatGPT conversations.

## Data handled locally

Prompt Otter reads the ChatGPT page in the browser to identify the user's prompts, highlight them, build a searchable prompt list, and jump between prompts.

Prompt Otter does not send prompts, chat content, browsing data, analytics, identifiers, or usage data to any server.

## Local storage

Prompt Otter stores only local interface preferences in the browser, such as panel position, panel size, expanded/collapsed state, hidden state, and search text.

The prompt cache is kept in the page session and is rebuilt as ChatGPT loads conversation content.

## No tracking or analytics

Prompt Otter does not use analytics, advertising, tracking, accounts, API keys, or remote code.

## Data sharing

Prompt Otter does not sell, transfer, or share user data with third parties.
